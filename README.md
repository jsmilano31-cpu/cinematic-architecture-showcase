# Courtyard House

A local architectural presentation for a single fictional residence. The eight chapters combine a cinematic image hero, a design narrative, exterior views, interactive plans, interiors, a short film, a 3D massing study, materials, and a closing contact link. All sample project facts and architectural assets are demonstration content.

## Start locally

Use Node.js 22.12 or newer and npm. From this folder run:

```sh
npm ci
npm run dev
```

Open [the local showcase](http://127.0.0.1:3000). The visitor experience uses bundled demo data when Sanity is unconfigured. Both development and production servers bind to loopback. To serve the optimized build, run `npm run build` followed by `npm start`.

## Verify

```sh
npm run lint
npm run typecheck
npm run test:content
npm run build
npx playwright install chromium firefox webkit
npm test
```

Lint covers application, Studio, scripts, tests, configuration, CSS, Markdown, and JSON. Dependencies, build output, test artifacts, and generated Next types are excluded. The content tests exercise the starter dataset through the production GROQ projection. Playwright starts the production server on loopback port 3100 and tests desktop Chromium, mobile Chromium, Firefox, WebKit with an iPhone viewport, and the installed Edge browser. Set `TEST_PORT` to choose a different port. Edge requires Microsoft Edge installed locally.

## Connect an authorized Sanity project

1. Copy `.env.example` to `.env.local`. Set the public project ID, dataset name, and canonical site URL. Supply a **server-only Viewer token** in `SANITY_API_READ_TOKEN` for draft preview. Editor writes use the editor’s authenticated Studio account.
2. In the project’s Sanity settings, allow the exact local Studio origin with credentials, for example `http://127.0.0.1:3000`. Use the same hostname for the presentation and Studio. The live published-content subscription uses a readable published dataset.
3. Run `npm run demo:dataset` to generate two editable singleton documents in `.qa/demo.ndjson`. This command only writes a local file. When separately authorized to write to the chosen dataset, use Sanity’s dataset import with **missing-document** behavior, for example `npx sanity dataset import .qa/demo.ndjson DATASET_NAME --missing`. The seed references the bundled local media.
4. Restart the app and open [Project Studio](http://127.0.0.1:3000/studio). The Project and Site settings items open the corresponding singleton documents. Studio provides editor sign-in. With no connection settings, the route explains setup.
5. Open Presentation to compare an unpublished edit with the site. Sanity validates the preview secret on the server. The draft session reads uncached draft data, refreshes while visible, and offers an exit link. An independent anonymous browser sees published content. Publishing changes uses Sanity Live for updates without rebuilding the app.

`NEXT_PUBLIC_MEDIA_HOSTS` accepts comma-separated, exact HTTPS hostnames for approved media. Sanity’s asset CDN and project-local files in `/demo/` are supported by default. Restart after changing hosts. Supply valid CORS headers for external models and caption tracks. Signed preview links are generated by Sanity.

## Editor guide

- **Chapters and text.** In Project, reorder the Sections array or edit a chapter’s title, navigation label, introduction, and visibility. Set the compact navigation choices in Site settings. The hero requires a project title and image or poster. A background film is optional.
- **Plans and rooms.** Add a floor with a unique ID and an uncropped plan. For a URL image, include the drawing’s actual pixel dimensions. Add rooms with stable IDs, the corresponding floor ID, optional area in square metres, a description, and ordered images. In the floor’s hotspots, choose the room by ID and click the placement preview, drag the marker, move it with the arrow keys, or enter percentages. Optional polygon vertices use the same 0–100 coordinate system. After replacing a plan, review every hotspot in Presentation at desktop and phone widths.
- **Images.** Add a meaningful alternative description to each editorial image. Uploaded images take precedence over demo URLs. Use captions, credit, category, optional room ID, and Sanity’s focal point. Gallery order follows the array order.
- **Immersive media.** Supply a poster, a short description, and a direct streaming-friendly video or file. Use a WebVTT caption track and transcript for speech. Canonical Vimeo player and YouTube privacy-enhanced embed URLs work when their host is approved. Use a web-optimized GLB or glTF for the model. Aim for a self-contained GLB under 5 MB, with a reduced version for anything larger. The local massing model is approximately 457 KiB. Omit a media object to hide that experience.
- **Review.** Verify room assignments, units, image rights, location precision, branding, and contact details before publishing real content. The local page uses noindex and disallows crawling. Public release requires separate approval.

## Replace the demonstration content

Replace the Fieldwork wordmark, Courtyard House name and copy, example email, schematic areas and project facts, material swatches, seven generated renders, both floor drawings, 15.5-second silent montage, and the model and its axonometric poster. The floor geometry fixture is in `src/content/plan-geometry.json`. Media files are in `public/demo/`. The imagery inventory records the generation prompts and image sizes. [Demo imagery](docs/demo-imagery.md)

## Later deployment

This is a Next.js App Router application with a standard Vercel build command of `npm run build`. After public release is approved, configure the authorized deployment’s environment values, canonical URL, Studio CORS origins, approved media, and indexing policy. Verify anonymous and draft sessions independently on the intended domain before sharing it.
